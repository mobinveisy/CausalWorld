# GitHub Pages Landing

This folder contains the animated 3D-style landing page for **CausalWorld**.

## Deploy with GitHub Pages

### Option 1: Root deployment
If your repository is configured to deploy from the `site/` folder through a Pages workflow,
publish this directory.

### Option 2: Simple manual deployment
Copy these files to the repository root (or to `/docs`) and set GitHub Pages to serve from there.

## Main files
- `index.html`
- `styles.css`
- `script.js`
