# Gate before writing the paper

We only move to strong paper claims after:

- [ ] synthetic full model beats no-context on CEE
- [ ] full model beats no-effect ablation on CEE across >= 5 seeds
- [ ] interpolation and extrapolation reported
- [ ] oracle baselines reported
- [ ] latent probe + PCA reported
- [ ] real matched-counterfactual dataset captured
- [ ] real tracking visually audited
- [ ] full model beats relevant baselines on real CEE
- [ ] confidence intervals / mean ± std
- [ ] failure cases documented
- [ ] exact split manifest released
- [ ] no claim of "first" until literature search at submission time
