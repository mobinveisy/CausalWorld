# Release checklist

## Before GitHub publication
- [ ] Replace `YOUR_GITHUB_USER` with your GitHub username.
- [ ] Run `python run_tests.py`.
- [ ] Run `python scripts/verify_release.py`.
- [ ] Confirm no datasets or large checkpoints are committed.
- [ ] Confirm dataset licenses/citations are retained.

## Before paper submission
- [ ] Full five-seed suite complete.
- [ ] Physion++ experiments complete.
- [ ] GAUGE validation complete.
- [ ] Final tables and figures generated.
- [ ] Failure cases reviewed.
- [ ] Final novelty/literature search complete.
- [ ] Freeze a version/tag.
- [ ] Archive the final public version on Zenodo after the anonymity constraints allow it.
