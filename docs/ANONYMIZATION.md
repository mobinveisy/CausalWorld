# Double-blind submission checklist

Before a double-blind submission:

- Do not include a personal GitHub link without checking the venue policy.
- Remove author names, emails, personal domains and identifying badges.
- Do not expose identifying Git history to reviewers.
- Prefer supplementary material or an anonymous repository if the venue permits it.
- Re-check the target venue's current anonymity policy immediately before submission.

After acceptance, restore public GitHub / Colab / Zenodo links.
